## 7. Remaining issues
- /create TBT ~510 ms: ~80 KB of unminified inline JS/CSS, mostly unused on first view. Next step: move the tool to a bundled build and minify, then split poster code from wish code.
- Brand domain: `*.vercel.app` limits trust and ranking; use a custom domain and update `SITE` in `_src/layout.py`, `create.html`, `robots.txt`.
- Backlinks and Search Console data are what move rankings now.
- Urdu/Arabic text needs a native-speaker check.
- Analytics IDs are empty until you paste them in `assets/analytics.js`.
